# 在线用户 - 测试用例

> 接口：GET /monitor/online/list
> 说明：获取当前在线用户列表
> 模块：系统监控 > 在线用户

## TC-ONLINE-001

| 项目 | 内容 |
|------|------|
| 用例ID | TC-ONLINE-001 |
| 用例标题 | 在线用户列表 - 正常场景: 获取在线用户列表 |
| 优先级 | P0 |
| 前置条件 | 已登录，有用户在线 |
| 测试类型 | 功能测试 |

**测试数据：** 无额外参数

**测试步骤：** 
| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 发送 GET /monitor/online/list | HTTP 200, code=200, 返回 rows 列表 |

**断言清单：**
- HTTP 状态码 = 200
- 业务码 code = 200
- 返回数据包含 rows 字段
- rows 为列表类型
