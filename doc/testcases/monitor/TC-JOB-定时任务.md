# 定时任务 - 测试用例

> 接口：GET /monitor/job/list, GET /monitor/job/{jobId}
> 说明：定时任务列表查询及详情
> 模块：系统监控 > 定时任务

## TC-JOB-001

| 项目 | 内容 |
|------|------|
| 用例ID | TC-JOB-001 |
| 用例标题 | 定时任务列表 - 正常场景: 获取定时任务列表 |
| 优先级 | P0 |
| 前置条件 | 已登录 |
| 测试类型 | 功能测试 |

**测试数据：** 无额外参数

**测试步骤：**
| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 发送 GET /monitor/job/list | code=200, 返回 rows 列表 |

**断言清单：**
- HTTP 状态码 = 200
- 业务码 code = 200
- 返回数据包含 rows 字段
- rows 为列表类型
