# 服务监控 - 测试用例

> 接口：GET /monitor/server
> 说明：获取服务器运行状态信息（CPU、内存、JVM、磁盘等）
> 模块：系统监控 > 服务监控

## TC-SERVER-001

| 项目 | 内容 |
|------|------|
| 用例ID | TC-SERVER-001 |
| 用例标题 | 服务监控 - 正常场景: 获取服务器信息 |
| 优先级 | P0 |
| 前置条件 | 已登录 |
| 测试类型 | 功能测试 |

**测试数据：** 无参数

**测试步骤：**
| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 发送 GET /monitor/server | code=200, 返回 data 对象 |

**断言清单：**
- HTTP 状态码 = 200
- 业务码 code = 200
- 返回数据包含 data 字段
- data 为字典类型
- data 包含 cpu、mem、jvm、sys 等关键字段
