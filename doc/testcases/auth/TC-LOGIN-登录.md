# 登录接口 - 测试用例

> 接口：POST /login
> 请求体：LoginBody { username, password, code, uuid }
> 模块：认证模块

---

## TC-LOGIN-001

| 项目 | 内容 |
|------|------|
| **用例ID** | TC-LOGIN-001 |
| **用例标题** | 正常登录 - 所有参数正确 |
| **优先级** | P0（Critical） |
| **前置条件** | 1. 服务正常运行；2. 已获取有效验证码uuid |
| **测试类型** | 功能测试 - 正常场景 |

**测试数据：**
| 参数 | 值 | 说明 |
|------|-----|------|
| username | admin | 有效用户名 |
| password | admin123 | 正确密码 |
| code | 1234 | 验证码 |
| uuid | (动态获取) | 从 /captchaImage 获取 |

**测试步骤：**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | GET /captchaImage 获取uuid | HTTP 200，返回有效uuid |
| 2 | POST /login 传入上述参数 | HTTP 200 |
| 3 | 解析响应 JSON | 有效 JSON |
| 4 | 检查 code 字段 | code == 200 |
| 5 | 检查 token 字段 | token 存在且不为空字符串 |

**断言清单：**
- `resp.status_code == 200`
- `data["code"] == 200`
- `"token" in data`
- `len(data["token"]) > 0`
