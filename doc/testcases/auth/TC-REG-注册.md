# 注册接口 - 测试用例

> 接口：POST /register
> 请求体：RegisterBody { username, password, code, uuid }
> 模块：认证模块

---

## TC-REG-001

| 项目 | 内容 |
|------|------|
| **用例ID** | TC-REG-001 |
| **用例标题** | 正常注册 - 新用户注册成功 |
| **优先级** | P0（Critical） |
| **前置条件** | 1. 服务正常运行；2. 已获取有效验证码uuid |
| **测试类型** | 功能测试 - 正常场景 |

**测试数据：**
| 参数 | 值 | 说明 |
|------|-----|------|
| username | testuser_{timestamp}_{random} | 动态生成唯一用户名 |
| password | Test123456 | 符合要求的密码 |
| code | 1234 | 验证码 |
| uuid | (动态获取) | 从 /captchaImage 获取 |

**测试步骤：**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | GET /captchaImage 获取uuid | HTTP 200 |
| 2 | 生成唯一用户名 | - |
| 3 | POST /register 传入参数 | HTTP 200 |
| 4 | 检查 code 字段 | code == 200，注册成功 |

**断言清单：**
- `resp.status_code == 200`
- `data["code"] == 200`
