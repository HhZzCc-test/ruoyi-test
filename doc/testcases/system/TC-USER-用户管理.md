# 用户管理 - 测试用例

> 接口：GET /system/user/list, GET /system/user/{userId}
> 说明：用户管理模块，包含用户列表查询和用户详情查询
> 模块：系统管理

---

## TC-USER-001

| 项目 | 内容 |
|------|------|
| **用例ID** | TC-USER-001 |
| **用例标题** | 正常场景 - 获取用户列表 |
| **优先级** | P0（Critical） |
| **前置条件** | 已登录获取有效Token |
| **测试类型** | 功能测试 - 正常场景 |

**测试步骤：**
| 步骤 | 操作 | 预期结果 |
|------|------|------|
| 1 | 发送GET /system/user/list请求 | HTTP 200 |
| 2 | 验证响应体 | code=200, 包含rows和total字段 |
| 3 | 验证字段类型 | rows为list, total为int |

**断言清单：**
- HTTP状态码 = 200
- 业务码 code = 200
- 字段 rows 存在且为列表类型
- 字段 total 存在且为整数类型
- 响应时间 < 3s
